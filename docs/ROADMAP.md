# Дорожная карта

0. Фундамент (эта итерация): требования, документы, health endpoint, схема и окружение. Готовность — сборка/health/db migration в локальной среде.
1. Identity/profile: регистрация, безопасная сессия, профиль и миграционные тесты.
2. Friends/safety: запросы, принятие, блокировки, доступ к ресурсам.
3. Places/routing: сравнить поставщиков по целевому рынку и лицензиям; реализовать адаптеры, затем поиск и внешний маршрут.
4. Вертикальный путь встречи: создать, пригласить, ответить, изменить, отменить; проверки прав и идемпотентности.
5. Напоминания/outbox/push; редактирование расписания и дедупликация.
6. Flutter MVP: локализация RU, состояния ошибок/пустоты/загрузки, профиль и сценарий встречи.
7. Геолокация с добровольным согласием, персонаж и простая комната.
8. Чаты, публичные активности, 3D и дополнительные рынки после проверки MVP.

Зависимости: этапы 1→2→4; 3 параллелен identity, но встрече нужен выбранный интерфейс; 5 требует 4; мобильный клиент может начинаться параллельно после API контрактов. Блокеры: JDK 21/Maven/Docker для сборки и БД, решение рынка и ключи/договор карт, выбранный push-провайдер. Критерии этапов — воспроизводимый сценарий и проверяемые права/данные, не только наличие экранов.
