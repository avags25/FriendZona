# Решения и открытые вопросы

## Принято
- Модульный монолит Spring Boot, PostgreSQL/PostGIS, Flyway; без ранних микросервисов/Redis.
- Время встречи хранить как UTC instant плюс IANA timezone; геокоординаты geography WGS84.
- Поставщики мест и маршрутов изолированы интерфейсами; решения по рынку отложены.
- В MVP пользователь может участвовать без постоянной геолокации; stale координаты не выдаются как текущие.
- Начальная схема — каркас пользователей и встреч, не готовая бизнес-функция.

## Неопределённости
- Первый рынок и применимое законодательство.
- Поставщик карт/мест/маршрутов и условия хранения/отображения результатов.
- Механизм аутентификации, push, хранилище медиа и бюджет.
- Конкретная аудитория и пороги метрик — требуют исследования.

## Проверенные исходные данные
Spring Boot 4.1.1 официально поддерживает Java 17–26, поэтому совместим с целевой Java 21. География, коммерческая лицензия, тарифы и хранение результатов карт требуют проверки по выбранному рынку и договору непосредственно перед интеграцией.

## Краткое сравнение картографических кандидатов (официальные страницы, просмотр 2026-10-20)
| Поставщик | Подтверждено документацией | Что проверить до выбора |
|---|---|---|
| 2ГИС | Places API ищет организации/адреса/категории; Routing API документирует пешком, авто, велосипед и общественный транспорт. Облачный и on-prem варианты. | Покрытие по выбранным странам, тариф/лимиты, коммерческие условия и ограничения кэширования по конкретному тарифу. |
| Яндекс | Есть мобильный MapKit; коммерческая тарификация/лимиты зависят от продукта, а тарифы различаются по API и MAU/запросам. | Фактическое покрытие и доступность API в странах запуска, маршруты и условия хранения/использования данных. |
| Google Maps Platform | Places и Routes API; Routes перечисляет пеший, автомобильный, велосипедный и общественный транспорт. Place ID разрешено хранить, кэширование большинства содержимого Routes ограничено; отображение требует соблюдения атрибуции/условий. | Тарифы, доступность и требования для страны/юрисдикции, соответствие условиям и стоимость при прогнозе нагрузки. |

Предварительного победителя нет: рынок не выбран, сравнение покрывает доступность задокументированных функций, а не качество покрытия/цену в целевом городе. Перед реализацией сохранить ссылки на актуальные условия конкретного продукта и получить коммерческое подтверждение.
